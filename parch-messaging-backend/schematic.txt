Backend:
- A database to store file metadata, comments, and users.
- An API to handle file operations, user management, and comments

Frontend
- A user interface to upload/view files and add/view comments.
- A mechanism to update comments in real time (e.g., websockets or polling).

Architecture
- Database: Choose a database like PostgreSQL (relational) or MongoDB (NoSQL) for storing files and comments.
- Backend: Use a Django to serve APIs.
    - 3 DB tables: users, files, comments
- Frontend: Use frameworks like React for UI.

API endpoints:
/files (POST)
- Send a file to back end

/files (GET)
- Retrieve files from backend

/comments (GET)
- Retrieve all comments 

/files/{id}/comments
- Retrieve all comments for a specific file

/users/{id}
- Retrieve user information

Potential Endpoints:
/api/files/	GET	Fetch all files
/api/files/	POST	Add a file
